# 실제 종목 연결 및 거래 차트 (2026-09-13)

## 데이터

토스증권 공식 Open API `/api/v1/candles`를 `interval=1d`, `count=200`, `adjusted=true`로 호출했다. 삼성전자(005930), SK하이닉스(000660), NAVER(035420)를 각 15페이지씩 수집했다. 종목별 3,000행, 2014-06-24~2026-09-11이며 원본은 `data/raw/toss-file-20260913T094935Z`에 보관한다. 수집 상한 때문에 최초 상장일까지 확보했다는 의미는 아니다.

`python -m lab.cli import-toss <원본 폴더> <종목 코드> <종목명>`으로 로컬 데이터 버전을 등록한다. 공급원은 토스 단일 공급원이다. KST 날짜로 변환하고 오름차순 정렬, 숫자 유효성·양수 가격·비음수 거래량·OHLC 관계를 검사한다. 페이지 경계에서 완전히 같은 중복만 제거하며 값이 다른 동일 거래일은 거부한다. 결측 거래일을 임의로 생성하거나 서로 다른 공급원의 값을 합치지 않는다.

공식 명세는 수정주가 적용 여부만 설명한다. 분할·배당별 상세 조정 방식, 거래소 달력과의 결측 대조, 저장·표시 권한 확인은 남아 있다. 이를 데이터 메타데이터와 화면에 명시하고 **로컬 탐색용**으로 등록한다. 배당 현금흐름을 포함한 총수익률로 해석하면 안 된다. 모든 실제 데이터 버전의 `publication_allowed=false`이며 공개 내보내기 대상에서 제외된다. 실시간 시세 자동 갱신은 하지 않는다.

공식 스키마: [토스증권 Open API](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json).

## 실험 생성

브라우저에서 POST 요청은 202로 접수되었으나 계산 라이브러리를 불러오는 동안 작업 상태가 queued에 머무르는 것을 재현했다. 이후 작업은 완료되었으므로 데이터베이스 저장 실패로 단정하지 않는다. 작업자가 계산 라이브러리를 불러오기 전에 running을 기록하도록 변경했다. 제출 직후 작업 ID와 진행 안내를 표시한다.

또한 자동 새로고침 성공 시 실행 오류를 지우던 상태 처리를 분리했다. 실패 안내는 사용자가 다음 작업을 수행할 때까지 유지하며 오류 위치로 이동한다. 데이터 변경 시 기간을 확보 범위에 맞추고, 최소 10거래일 미만은 작업 생성 전에 422로 거부한다. 완료·실패·취소 상태를 각각 안내한다.

## 차트

Plotly 금융 번들을 분석 화면에서만 지연 로드한다. 일봉 캔들 / OHLC 막대 / 종가 선 전환, 거래량 막대, 1·3·6개월·전체 기간 버튼, 범위 선택기와 확대·이동 도구를 제공한다. 주말만 압축하고 달력 검증 전 휴장일을 추측하지 않는다.

매수 ▲ 빨강, 매도 ▼ 파랑을 실제 백테스트 체결가 좌표에 표시한다. 툴팁에는 날짜, 시가·종가 기준, 체결가, 수량, 거래금액, 비용을 표시한다. 가격은 슬리피지가 반영된 모의 체결 가격이며 실제 주문 내역이 아니다. 거래 표의 위치 보기에서 해당 거래 전후로 확대한다. 평가 자산과 낙폭도 전환할 수 있다.

새 결과 JSON에는 평가 구간 OHLCV와 각 거래의 `phase=open|close`를 포함한다. 이전 저장 결과는 로컬 결과 API에서 같은 고정 데이터 버전의 OHLCV를 조회하여 표시하되 저장 파일을 수정하지 않는다. 공개 내보내기에는 신규 원본 일봉 필드를 자동 추가하지 않는다.

차트 참고: [Plotly 공식 캔들 차트 문서](https://plotly.com/javascript/candlestick-charts/).

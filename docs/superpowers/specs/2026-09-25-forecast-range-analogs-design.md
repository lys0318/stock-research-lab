# 미래 예측 발전: 예측 범위·근거·비슷한 과거 차트 — 2026-09-25

## 배경
Ridge 경로 예측은 대부분 종목에서 거의 평평하다. 카카오 20일 기준 실제 변화 표준편차 ±11.5%, 예측값 표준편차 ±1%, 설명력 R² 0.008. 4종목 2년 검증에서 13지표 부스팅·패턴 유사도 모두 "가격 유지" 가정보다 오차가 작지 않았다. 반면 최근 60일 변동성 기반 80% 범위는 5·20일에서 실제 포함률 76~86%로 잘 맞았다(60일은 강한 추세 종목에서 49~55%). 따라서 방향을 억지로 키우지 않고 범위·근거·시나리오를 보여준다.

## 계산 (`lab/forecast.py`, 응답은 기존 `/api/forecast`에 필드 추가)
- 중심: 기존 Ridge 경로(k=1..H 로그 변화).
- 범위: σ = 최근 60거래일 일별 로그수익률 표준편차. k일 표준편차 σ√k. 정규 근사로 p10·p25·p75·p90 가격(중심 로그값 ± z·σ√k).
- 확률: H일 기준 P(상승), P(+10% 이상), P(−10% 이하). 정규 근사, 두꺼운 꼬리 미반영을 안내.
- 근거: 최종 모델의 H번째 출력에 대해 계수 × 표준화된 오늘 지표값, 절편(평균 추세). 합 = 예측 로그 변화. 한글 이름으로 반환하고 절댓값 순 정렬.
- 비슷한 과거 차트: 같은 종목, 창 W=60. 로그가격을 창 끝 기준 0으로 맞춘 61점 경로의 유클리드 거리. 후보는 창 끝 j + H < 오늘 인덱스(결과가 오늘 전에 확정). 거리 순으로 서로 20거래일 이상 떨어진 5개. 각 구간의 이후 H일 흐름을 오늘 종가에 적용한 시나리오 가격 경로, 미니 차트용 정규화 경로(W+H+1점), 시작·끝 날짜, 이후 변화율, 평균 차이(거리/√61).
- 검증 추가: 평가 구간(최근 2년)에서 80%·50% 범위 포함률(중심은 평가용 모델, σ는 당시 최근 60일), 시나리오 방향 적중률(5거래일 간격 표본, 후보는 j + H < i).

## 화면 (`Forecast.tsx`, `ResearchCharts.tsx`)
1. 요약: 예상 가격(중앙), 80% 범위 문장, 확률 칩 3개.
2. 차트: 80%(옅게)·50%(진하게) 부채꼴, 중앙 점선, 시나리오 5개 가는 선. 차트 도구에 '범위'·'시나리오' 토글.
3. 예측 근거: 지표별 막대(상승 빨강, 하락 파랑), 합계 = 중앙 예측.
4. 비슷한 과거 차트: 카드 5개(미니 SVG: 과거 60일 회색 + 이후 H일 색), 날짜, 이후 변화, 평균 차이. 요약 "5번 중 n번 상승, 중앙값".
5. 검증: 방향 적중률, 평균 오차 vs 가격 유지, 80% 범위 적중률, 시나리오 방향 적중률. 80% 범위 적중률 70% 미만이면 경고.

## 테스트
범위 순서(p10<p25<중앙<p75<p90)와 확장, 확률 범위와 up10≤up, 근거 합 = 예측 로그 변화, 시나리오 5개·20일 간격·미래 미사용(j+H<i), 검증 지표 0~1. 화면은 브라우저로 카카오 확인.

# 종목 작업 공간 개편 설계 — 2026-09-25

## 목표
종목 검색 → 기간·전략 선택 → 백테스트 결과(얼마를 벌었고 언제 사고팔았는지) → 미래 가격 경로 예측을 한 흐름으로 제공한다. 디자인 시스템을 Coinbase 참고에서 OpenAI Platform 참고로 바꾼다. 백테스트 엔진·작업 시스템·AWS 코드는 유지한다.

## 화면 흐름
1. 홈: "어떤 종목을 분석할까요?" 검색 입력(종목명·코드), 저장된 종목 칩, 최근 실험 카드(종목·전략·수익률·기간).
2. 종목 작업 공간: 머리글(종목명·코드·시장·데이터 기준일·최근 종가), 탭 두 개.
   - 과거 백테스트: 왼쪽 설정(기간 1년/2년/5년/직접, 전략 카드 3종, 이동평균 기간, 시작 자금, 접힌 고급 설정: 수수료·세금·슬리피지), 오른쪽 결과. 실행 후 작업 완료를 1초 간격으로 조회해 결과를 자동 표시한다.
   - 미래 예측: 기간 5/20/60거래일 선택, 실제 가격 + 예측 경로 점선, 검증 수치.
3. 결과: "시작 자금 → 최종 자산(수익률)", 같은 기간 매수 후 보유 수익률, 최대 낙폭, 거래 횟수, 승률. 가격 차트(▲ 매수 / ▼ 매도), 자산·낙폭 차트, 왕복 거래 표(매수일·가격 → 매도일·가격, 보유일, 수익률, 손익).
4. 실험 기록, 클라우드 실험, 데이터 안내: 기존 내용 유지, 새 디자인 적용. 기록에서 결과를 열면 해당 종목 작업 공간으로 이동한다.

## 차트
- 가격 차트 종류: 캔들, OHLC 막대, 선, 영역. 백테스트 결과와 미래 예측 차트 모두 같은 전환 컨트롤을 사용한다.
- 이동평균선 겹쳐 보기: 5·20·60·120일 토글(프론트엔드 계산).
- 거래량 막대, 기간 버튼, 범위 선택기는 유지한다.
- 예측 차트: 최근 약 6개월 실제 가격 + 마지막 종가에서 이어지는 예측 점선, 마지막 점에 예상 가격 라벨.

## 백엔드
- `GET /api/stocks?q=`: 저장된 데이터 종목 + 토스 KOSPI·KOSDAQ 전체 종목(securityType=STOCK, `data/universe.json`, 하루 1회 갱신)을 합쳐 이름·코드 부분 일치로 최대 20개 반환. 각 항목에 저장 여부(`dataset_id`)와 토스 연결 여부. 키가 없거나 목록 조회 실패 시 저장된 종목만.
- `POST /api/stocks/{symbol}/prepare` (X-Research-Local 필요): 종목의 최신 실제 데이터 버전을 반환. 없거나 끝 날짜가 오늘보다 5일 넘게 이전이고 키가 있으면 토스에서 최대 15페이지 수집 후 등록. 키가 없고 저장본이 없으면 422. 같은 종목 동시 수집은 잠금으로 직렬화.
- `GET /api/forecast?dataset_id=&horizon=5|20|60`: 동기 계산.
  - 입력 특징: 기존 `features()` 6종.
  - 목표: k=1..H에 대해 log(close[t+k]/close[t]). StandardScaler → Ridge(alpha=1.0) 다중 출력 1회 학습.
  - 검증: 최근 2년(데이터 부족 시 최근 20%)을 평가 구간으로 두고, 정답 종료일이 평가 시작 전인 행만 학습. H일 뒤 방향 적중률, H일 뒤 가격 평균 절대 오차율, 무변화 예측(오늘 가격 유지)의 평균 절대 오차율.
  - 최종 예측: 정답이 확정된 모든 행으로 재학습 후 마지막 거래일 특징으로 H개 경로 산출. 날짜는 다음 거래일부터(주말·한국거래소 휴장일 제외, holidays 라이브러리 XKRX).
  - 응답: last_date, last_close, path[{date, price}], evaluation{hit_rate, mape, naive_mape, test_rows, test_start}, 안내 문구.
  - 부족 데이터(학습 100행·평가 30행 미만) 422.
- 기존 `/api/datasets`, `/api/runs*`, `/api/benchmarks` 유지.

## 프론트엔드 구조
`main.tsx`(앱 셸·사이드바·라우팅 상태), `api.ts`(타입·fetch·포맷), `Home.tsx`, `Workspace.tsx`(설정·실행·결과·예측 탭), `ResearchCharts.tsx`(가격 차트 공용: 종류 전환·이동평균·거래 표시·예측 경로), `Pages.tsx`(기록·클라우드·데이터 안내). 공개 모드는 검색·실행·예측 없이 공개 결과 카드와 결과 보기만.

## 오류와 상태
검색 중, 수집 중(약 5초 안내), 계산 중, 완료, 실패, 취소를 텍스트로 구분한다. 수집·예측·실행 오류는 해당 영역 위 alert로 표시한다. 예측 결과에는 "예측은 과거 패턴의 통계적 추정이며 투자 조언이 아니다"와 검증 수치를 항상 함께 표시한다.

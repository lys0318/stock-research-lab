# PRD — 주식 전략 연구실
버전 0.1 · 2026-09-09

## 연구 목적
국내 주식 예측과 백테스트를 계산 부하로 삼아 AWS 병렬 처리의 성능·비용을 검증한다. 성과가 우수한 전략 발굴은 부차적이며 수익 보장을 제품 목표로 삼지 않는다.

## 사용자와 권한
연구자: 로컬에서 데이터 등록, 작업 제출·조회·취소, 결과 CSV 저장, 클라우드 CLI 실행.
방문자·교수: 공개 정적 사이트의 완료 결과만 조회. 계정·로그인 없음. 공개 웹에는 백엔드와 실행 기능이 없다.

## 기능 우선순위
P0: 데이터 검증·등록, 전략 3종, 시간순 모델 학습, 로컬 작업 상태, 결과 차트·거래 내역·CSV, 공개 내보내기 필터.
P1: 동일 이미지의 AWS 작업 실행, 반복 실험 및 보고서, CloudFront 정적 배포.
제외: 실제 주문, 뉴스·재무제표, 포트폴리오 최적화, 자동매매, 실시간 스트리밍.

## 흐름
1. 연구자가 API 원본을 확보하고 컬럼·가격 조정·기간·권한을 검증한다.
2. 정제 CSV와 메타데이터를 등록해 불변 데이터 버전을 만든다.
3. 종목·기간·전략·비용을 선택해 비동기 작업을 제출한다.
4. 완료 결과의 수익률·낙폭·거래·예측 점수를 확인한다.
5. 동일 작업 목록을 단일·병렬 조건으로 실행해 비교한다.
6. 표시 권한이 있는 실제 데이터 결과만 정적 사이트로 내보낸다.

## 완료 조건
계산 손검산, 데이터 누수, 단일·병렬 결과 일치, 취소 및 공개 접근 경계 테스트 통과.
로컬 UI에서 실행→완료→상세 조회가 가능하다. 공개 결과 없는 경우 빈 화면을 설명하며 가짜 수치로 채우지 않는다.

## 제약과 운영
12주·AWS 월 3만 원 목표. 로컬 먼저 개발. 실제 토스 키·데이터 이용 조건 미확인.
월 예산은 강제 차단 장치가 아니며 데이터·트래픽·이미지 저장 비용도 별도 추적한다.

# 데이터·모델 명세

## 토스 검증 단계
1. 공식 WTS에서 Open API 신청, 허용 IP 등록. 키는 환경 변수로만 전달.
2. collect-toss로 원본 응답을 data/raw에 저장. 기본 1페이지, 명시적 최대 100페이지.
3. 공식 candles 문서와 응답 컬럼·타임존·일봉 의미·페이지 커서를 대조한다.
4. 삼성전자 005930, SK하이닉스 000660, NAVER 035420의 최초 조회일·누락을 기록한다.
5. 수정 여부, 분할·배당 반영, KRX/NXT 거래 범위, 저장·표시 권한을 확인한다.
6. 검증된 원본을 date,open,high,low,close,volume CSV로 변환 후 등록한다.
현재 자동 원본→정제 변환기는 미확정이다. 관측하지 않은 스키마나 수정 의미를 추측하지 않는다.

## 데이터 계약
date는 ISO 거래일, 오름차순·중복 없음. 가격은 양수, 거래량은 음수 불가, 무한대·결측 불가.
high >= open/close/low, low <= open/close/high.
source, adjustment, symbol, name 필수. 공개 여부 기본 false.
adjustment=unknown은 등록 거절. 선언만으로 기업행사 검증이 완료되는 것은 아니다.
분할·배당 현금흐름은 현재 엔진이 자동 처리하지 않는다. 일관되게 조정된 가격 모형을 사용하고 이를 연구 가정에 기록한다. 원시 가격으로 기업행사를 가로지르는 실험은 사전 검증 없이 수행하지 않는다.

## 초기 범위
목표 2016~2025년. 실제 기간 확정 전 장기 연구 결과를 생성하지 않는다.
3종목 검증 후 업종이 다른 10종목 확대는 교수님 검토와 데이터 확보 후 진행.
가상 데이터는 000000, synthetic=true. 거래소 휴일을 재현하지 않는 개발 전용 영업일 데이터다.

## 예측 모델
StandardScaler→LogisticRegression, seed=42, 최대 반복 1000.
입력: 1/5일 수익률, 20/60일 평균 대비 가격, 거래량 변화, 20일 수익률 표준편차.
정답: t+1 시가 대비 t+5 종가 상승 여부.
최종 평가 시작 직전 1년을 검증 구간으로 둔다. 그 이전을 학습.
정답 종료일이 다음 구간에 진입하는 행은 제거. 전처리는 학습 구간에서만 fit.
검증 정확도로 0.50/0.55/0.60/0.65 중 임계값 선택, 동률은 낮은 값. 최종 평가에 다시 맞추지 않는다.
평가: accuracy, Brier score. 최소 학습 100행·검증 30행·평가 10행 및 학습 두 클래스 필요.

## 매매·비용
현금만 사용, 정수 주식, 레버리지·공매도 없음.
모델: t 신호→t+1 시가 매수→5번째 보유 거래일 종가 매도. 추가 매수 없음.
MA: 이전 종가가 이전 MA보다 높으면 다음 시가 매수, 아니면 다음 시가 매도.
hold: 평가 첫 시가 매수, 마지막 종가 매도.
평가 마지막 종가에 강제 청산. 종료 전 5일 보유할 수 없는 모델 진입은 생략.
매수 비용=수량×체결가×수수료, 매도 비용=수량×체결가×(수수료+입력 세금).
세금 기본 0은 '면세'가 아니라 실험 입력값이며 실제 시장 세율이라고 주장하지 않는다.
슬리피지 기본 0.0005: 매수 가격 증가·매도 가격 감소.
